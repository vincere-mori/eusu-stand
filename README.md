# Стенд ЭУСУ

Тренажёр по лабораторным работам курса «Электронные устройства систем управления», ИТМО.

Восемь стендов (ЛР1-ЛР8): анимированные схемы на ОУ LT1001 с бегущим током, поиск неисправностей по осциллограмме, вопросы «что будет, если», шпаргалки и экзамен на время.

Играть: https://eusu-stand.vercel.app
